# Yelp Auto-Reply — расширение для Chrome

Отвечает вашим клиентам во «Входящих» Yelp for Business **за вас** — по-человечески, вашим тоном, по вашим ценам и правилам. Работает прямо в вашем браузере (вы уже залогинены в Yelp), без сервера.

## Установка за 3 шага

Chrome Web Store не пропускает автоматизацию Yelp, поэтому ставим напрямую (это безопасно и занимает минуту):

1. **Скачайте** папку `extension/` (или весь проект → распакуйте).
2. Откройте в Chrome адрес **`chrome://extensions`** → включите **«Режим разработчика»** (переключатель справа вверху).
3. Нажмите **«Загрузить распакованное расширение»** (Load unpacked) → выберите папку **`extension`**.

Готово — справа вверху появится красный значок 💬. Откроется окно приветствия → **«Начать настройку»**.

## Настройка (2 минуты)

Мастер проведёт по шагам, всё простым языком:

1. **Подключить ИИ** — вставьте ключ (кнопка «Где взять ключ?» всё покажет). Есть кнопка **«Проверить подключение»** — сразу видно, что работает.
2. **Бизнес** — название, чем занимаетесь, город.
3. **Как отвечать** — ваше имя и тон (кнопки «Дружелюбный / Деловой / Простой»).
4. **Факты** — цены, часы, услуги (по строке).
5. **Правила** — что нельзя и когда передать диалог вам лично.
6. **Безопасность** — рабочие часы и лимит ответов в день.
7. **Готово** — нажимаете «Включить».

## Как пользоваться

- Нажмите на значок → большой переключатель **Вкл/Выкл**.
- **Держите открытой вкладку «Входящие» Yelp** (`biz.yelp.com/inbox`). Пока она открыта — бот проверяет сообщения и отвечает. Можно свернуть окно.
- В попапе видно: сколько ответов сегодня, что бот делал, и **«Требуют вашего ответа»** — сложные диалоги, которые бот не тронул.

## Что важно понимать

- **Нужен свой ключ ИИ.** Ответы генерирует Claude (Anthropic) или любой OpenAI-совместимый сервис по вашему ключу. Ключ хранится только в вашем браузере и уходит напрямую в выбранный сервис.
- **Вкладка Yelp должна быть открыта.** Расширение работает в странице Yelp, а не на сервере. Закрыли вкладку — бот на паузе.
- **Сложные случаи бот не трогает.** Злой клиент, возвраты, претензии (настраивается) — помечаются «нужен человек», вы отвечаете сами.
- **ToS Yelp.** Автоматизация интерфейса Yelp нарушает их правила. Встроенные лимиты, рабочие часы и человеческие задержки снижают, но не убирают риск блокировки. Используете на свой риск.
- **Yelp меняет верстку.** Все селекторы собраны в `content/selectors.js` (несколько вариантов на каждый элемент). Если Yelp что-то переделает и ответы перестанут уходить — правятся там.

## Структура

```
extension/
  manifest.json            Manifest V3
  background/
    service-worker.js      планировщик, решения, вызов LLM, состояние
    config.js              конфиг/состояние в chrome.storage
    prompt.js              системный промпт из настроек
    responder.js           Anthropic / OpenAI-совместимый / mock
  content/                 работа с живой страницей Yelp
    selectors.js           все селекторы biz.yelp.com
    inbox.js               чтение диалогов и переписки
    humanize.js            человеческие задержки и набор текста
    content.js             оркестратор: скан → решение → ответ
  popup/                   главный экран (Вкл/Выкл, статус, лента)
  options/                 мастер настройки
  welcome/                 экран после установки
  icons/                   иконки (сгенерированы tools/gen-icons.mjs)
  tools/
    gen-icons.mjs          генератор иконок
    ui-smoke.mjs           тест мастера со стабом chrome
    load-smoke.mjs         загрузка расширения в Chromium + проверка SW
```

## Разработчику

```bash
node tools/gen-icons.mjs              # перегенерировать иконки
xvfb-run -a node tools/ui-smoke.mjs   # прогон UI мастера (ловит ошибки JS)
xvfb-run -a node tools/load-smoke.mjs # реальная загрузка расширения в Chromium
```

Чистый JS, без сборки — папка грузится в Chrome как есть.
